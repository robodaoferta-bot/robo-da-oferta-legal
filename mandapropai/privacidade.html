Política de Privacidade

Última atualização: 17 de setembro de 2026

O MandaProPai ("nós", "nosso") opera o aplicativo de atendimento automatizado via WhatsApp para estabelecimentos comerciais. Esta política descreve como coletamos, usamos e protegemos as informações dos usuários.

1. Dados que coletamos

  • Número de telefone — fornecido pelo WhatsApp quando você envia uma mensagem ao estabelecimento.
  • Conteúdo das mensagens — texto das conversas de atendimento, usado para processar pedidos e melhorar o serviço.
  • Nome de perfil — nome público do seu perfil no WhatsApp.

2. Como usamos os dados

  • Processar e entregar pedidos feitos pelo WhatsApp.
  • Responder dúvidas e fornecer atendimento ao cliente.
  • Gerar perfis de preferência para personalizar o atendimento (quando ativado pelo lojista).
  • Melhorar a qualidade do serviço.

3. Compartilhamento de dados

Seus dados são compartilhados apenas com:

  • O estabelecimento comercial com o qual você está interagindo.
  • Provedores de infraestrutura necessários para operar o serviço (hospedagem, API do WhatsApp).
  • Serviços de inteligência artificial para processamento de linguagem natural (Google Gemini), sem identificação pessoal.

Não vendemos nem compartilhamos seus dados com terceiros para fins de marketing.

4. Armazenamento e segurança

Os dados são armazenados em servidores no Brasil, protegidos por criptografia em trânsito (HTTPS/TLS) e em repouso (tokens e dados sensíveis são cifrados com libsodium). O acesso é restrito a pessoal autorizado.

5. Retenção de dados

Mensagens de atendimento são mantidas pelo tempo necessário para a operação do serviço. Você pode solicitar a exclusão dos seus dados a qualquer momento.

6. Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (Lei 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento de dados.
  • Acessar seus dados.
  • Corrigir dados incompletos ou desatualizados.
  • Solicitar a exclusão de dados desnecessários.
  • Revogar o consentimento.

7. Contato

Para exercer seus direitos ou tirar dúvidas sobre esta política, entre em contato pelo e-mail: robodaoferta@gmail.com

8. Alterações

Esta política pode ser atualizada periodicamente. A data de última atualização será sempre indicada no topo desta página.
